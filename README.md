# ca_skill

Скиллы для Claude Code, используемые в работе цифровой студии [Visual Sense Lab](https://vsl74.ru).

## vsl-kp-generator

Генератор персонального коммерческого предложения под конкретного лида. На входе — только URL сайта компании, на выходе — готовое КП в виде HTML-документа по ссылке.

Что делает:

1. **Аудит сайта лида** через встроенный браузер — мобильная вёрстка, формы заявки, SEO-база (title, description, H1), консольные ошибки, скорость, актуальность дизайна.
2. **Аудит бизнеса по открытым источникам** — отзывы на 2ГИС и картах, соцсети, конкуренты в той же нише и городе.
3. **Диагностика** — 3–5 конкретных находок именно по этой компании, с последствиями для заявок и доверия.
4. **Подбор услуг** из прайса студии под найденные проблемы — 2–3 позиции, не больше.
5. **Публикация КП** как HTML-артефакта в фирменном стиле студии, с логотипом и фото основателя.

### Установка

```bash
git clone git@github.com:4EZ4KMI/ca_skill.git
mkdir -p ~/.claude/skills
cp -R ca_skill/vsl-kp-generator ~/.claude/skills/
```

После этого скилл подхватится в новых сессиях Claude Code.

### Использование

```
сделай КП для https://example.ru
```

Скилл срабатывает и на формулировки вроде «проаудируй сайт и накидай предложение», «подготовь предложение для лида», «собери КП по этому сайту».

### Структура

```
vsl-kp-generator/
├── SKILL.md              — воркфлоу: аудит → диагностика → подбор услуг → публикация
├── references/
│   └── brand.md          — бренд-досье: позиционирование, прайс, визуальные токены, тон голоса
└── assets/
    ├── template.html     — HTML-каркас КП в фирменном стиле
    └── brand/            — логотип и фотографии для вставки в документ
```

### Перед первым запуском: подставьте цены

В публичной версии суммы скрыты плейсхолдерами. Откройте `references/brand.md` и замените `{{ЦЕНА_САЙТ}}`, `{{ЦЕНА_ДИРЕКТ}}`, `{{ЦЕНА_ТАРГЕТ}}` и `{{БЮДЖЕТ}}` на свои значения — без этого скилл не соберёт блок со стоимостью.

### Настройка под свою студию

Скилл заточен под Visual Sense Lab. Чтобы использовать его в другой компании, правьте `references/brand.md` — там лежат прайс, контакты, позиционирование и цветовые токены, — и замените содержимое `assets/brand/`.

> Сгенерированное КП — черновик для ускорения подготовки: перед отправкой клиенту находки и стоимость проверяет менеджер.
