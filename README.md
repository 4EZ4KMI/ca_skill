# ca_skill

Скиллы для Claude Code, используемые в работе цифровой студии [Visual Sense Lab](https://vsl74.ru).

## vsl-kp-generator

Генератор короткого КП на одну страницу под конкретного лида. На входе — название или сайт компании, на выходе — HTML-артефакт и PDF для отправки клиенту.

Что делает:

1. **Быстрая разведка** — 2ГИС, ВКонтакте и сайт лида: ниша, есть ли сайт, входной оффер.
2. **КП на одну страницу A4** — заголовок-хук, три боли (сайт, Директ, таргет), бесплатный аудит, контакты. Без цен.
3. **Публикация** HTML-артефакта и сборка PDF с проверкой, что вышла ровно одна страница.

Подробное КП с ценами — только по прямой просьбе.

### Установка

```bash
git clone git@github.com:4EZ4KMI/ca_skill.git
mkdir -p ~/.claude/skills
cp -R ca_skill/vsl-kp-generator ~/.claude/skills/
```

После этого скилл подхватится в новых сессиях Claude Code.

### Использование

```
сделай КП для <название или сайт>
```

Скилл срабатывает и на формулировки вроде «проаудируй сайт и накидай предложение», «подготовь предложение для лида», «собери КП по этому сайту».

### Структура

```
vsl-kp-generator/
├── SKILL.md                   — воркфлоу: разведка → сборка → PDF
├── examples/
│   └── detskiy-centr.html     — эталон КП (обезличен)
├── references/
│   └── brand.md               — бренд-досье: контакты, прайс, стиль, тон
└── assets/
    ├── template.html          — каркас короткого КП
    ├── template-detailed.html — каркас подробного КП с ценами
    └── brand/                 — логотип и фотографии
```

### Для подробного КП: подставьте цены

В публичной версии суммы скрыты плейсхолдерами. Откройте `references/brand.md` и замените `{{ЦЕНА_САЙТ}}`, `{{ЦЕНА_ДИРЕКТ}}`, `{{ЦЕНА_ТАРГЕТ}}` и `{{БЮДЖЕТ}}` на свои значения — без этого подробное КП с ценами не собрать. Короткому КП цены не нужны.

### Настройка под свою студию

Скилл заточен под Visual Sense Lab. Чтобы использовать его в другой компании, правьте `references/brand.md` — там лежат прайс, контакты, позиционирование и цветовые токены, — и замените содержимое `assets/brand/`.

> Сгенерированное КП — черновик для ускорения подготовки: перед отправкой клиенту находки и стоимость проверяет менеджер.
